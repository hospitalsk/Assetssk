Hospital Asset Management - Updated package (SweetAlert2, Executive In-App Alerts, Department Allocation)

Files:
- Code.gs: Google Apps Script server code
- Index.html: Web app interface

Key Changes in this Update:
1. SweetAlert2 ทั่วทั้งเว็บแอป:
   - ปรับเปลี่ยนการแจ้งเตือน การยืนยัน (Confirm) และกล่องข้อความทั้งหมดเป็น SweetAlert2 สไตล์ Prompt เรียบร้อย สวยงาม และเข้ากับโทนระบบ
   - การแจ้งเตือน Toast มุมขวาบนอัตโนมัติ พร้อมไอคอนแสดงผล (Success / Error / Warning / Question)
   - ปรับการยืนยันลบข้อมูล, การนำเข้า Excel, การออกจากระบบ และการเปลี่ยนสถานะผู้ใช้ด้วย Modal ยืนยันของ SweetAlert2

2. เมนูแจ้งเตือนผู้บริหารภายในเว็บแอป (In-App Executive Notification Center):
   - เพิ่มกระดิ่งแจ้งเตือน 🔔 บน Topbar พร้อมตัวเลข Badge แจ้งเตือนแบบเรียลไทม์
   - เมนู "แจ้งเตือนผู้บริหาร" บนแถบเมนูด้านซ้าย มี Badge แจ้งเตือนจำนวนรายการที่ต้องติดตาม
   - แจ้งเตือน Pop-up ทันทีเมื่อผู้บริหารเข้าสู่ระบบ (Login) หากมีวัสดุหมดคลัง หรือครุภัณฑ์รอซ่อม
   - หน้าศูนย์แจ้งเตือนผู้บริหารแยกแท็บชัดเจน:
     * 📦 วัสดุถึงจุดสั่งซื้อ / หมดคลัง พร้อมสูตรคำนวณคาดการณ์ยอดใช้ล่วงหน้าและปุ่มเบิก/จัดซื้อ
     * ⚒️ ครุภัณฑ์ค้างซ่อม / รอดำเนินการ พร้อมปุ่มอัปเดตงานซ่อม
     * ⚠️ ครุภัณฑ์สภาพชำรุด / เสื่อมสภาพ เพื่อการตัดสินใจจำหน่ายหรือซ่อม
     * 📊 สรุปความต้องการแยกตามหน่วยงาน
     * ปุ่มพิมพ์รายงานแจ้งเตือนผู้บริหารขนาด A4

3. ระบบจัดสรรทรัพยากรตามหน่วยงาน (Department Allocation):
   - เพิ่มเมนู "จัดสรรตามหน่วยงาน" (⇄) บนแถบเมนูหลัก
   - แสดงสถิติและจำนวนครุภัณฑ์และวัสดุของแต่ละแผนกอย่างชัดเจน
   - เจ้าหน้าที่และหัวหน้ากลุ่มงานจะเห็นข้อมูลและจำนวนครุภัณฑ์/วัสดุของแผนกตนเองทันที
   - ผู้บริหารสามารถดูภาพรวมเปรียบเทียบทุกแผนก (Allocation Matrix) หรือเลือกดูรายแผนกได้
   - ฟังก์ชัน "จัดสรร/ย้าย": ย้ายสถานที่จัดเก็บ/ห้อง หรือเปลี่ยนผู้รับผิดชอบดูแลครุภัณฑ์
   - ฟังก์ชัน "เบิกจ่าย": เบิกวัสดุใช้งานในแผนกได้สะดวกรวดเร็ว

Deployment:
1. เปิด Apps Script project ที่ผูกกับ Google Sheets
2. แทนที่ Code.gs และ Index.html ด้วยไฟล์ชุดนี้
3. สั่ง Deploy > Manage deployments > แก้ไข (รูปดินสอ) > New version > Deploy
